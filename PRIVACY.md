# Privacy Policy for Batch Lecture Rater

**Last Updated:** August 26, 2026

---

## Introduction

Batch Lecture Rater ("we", "us", or "the extension") is committed to protecting your privacy. This Privacy Policy explains how our Chrome extension handles information.

---

## Data Collection

**Batch Lecture Rater does NOT collect, store, or share any personal data.**

Specifically, we do NOT collect:

- Personal identifiable information (name, email, address, etc.)
- Browsing history or website content
- Keystrokes or user activity tracking
- Location data
- Authentication credentials
- Any form of personal communications

---

## Data Processing

- No user data is collected or stored.
- The extension does not transmit any data to external servers.
- The extension only interacts with the university portal's DOM elements to automate rating selection and submission.
- All actions are triggered by the user and limited to the university portal pages.

---

## Permissions Used

| Permission | Purpose |
|------------|---------|
| **activeTab** | Used to access the current lecture sheet page when the user clicks the extension icon. |
| **storage** | Used to save user preferences (selected rating) locally in the browser. This data remains on your device only and is never transmitted anywhere. |
| **scripting** | Used to interact with the university portal's DOM elements to locate rating dropdowns and submit buttons. |
| **host_permissions** | Used to access the university portal URL where lecture sheets are listed. |

---

## Data Sharing

**We do NOT:**

- Sell user data to third parties
- Share data with advertisers
- Use data for purposes unrelated to rating lecture sheets
- Track or profile users
- Implement any analytics or tracking

---

## Security

The extension runs entirely in your browser. No data is sent over the internet or stored on any external server. All local data is stored using Chrome's built-in storage API and is isolated to your browser.

---

## Third-Party Services

**None.** The extension does not use any third-party services, APIs, or libraries that collect data.

---

## Your Rights

Since we don't collect personal data, there is no personal data to access, modify, or delete. If you have concerns:

- You can uninstall the extension at any time
- Clear browser storage via Chrome settings
